# HTML → Figma（网页版）

在浏览器里把网页**逐像素还原成可编辑图层**，支持单页与**整包（.zip）批量复刻**，
产出 SVG / 结构树，用于预览、导出与二次处理。

和插件版共享同一套内核（`core/`），所以两条路线出来的结果是一致的 —— 差别只在出口：
插件版出原生 Figma 图层，网页版出 SVG 与结构树。

## 起服务

网页版需要一个**静态服务器**（不能用 `file://`：整包解析、字体与资源内联都要求正常的同源环境）。

```bash
node serve.js            # 默认 http://127.0.0.1:8899
node serve.js 9000       # 指定端口
```

然后打开 `http://127.0.0.1:8899/web/index.html`。

## 用法

**输入模式** —— 粘贴整段 HTML（含 `<style>`），或粘贴一个网址（走 CORS 代理抓取）。

**文件模式** —— 拖入或选择 `.html` 单页、`.zip` 整包，支持多选；文件进入队列后可单项移除、一键全部复刻。

导入整包时逐页生成，产出：

- 每页一版 **SVG** 与**结构树 JSON**；
- **交互全景画布**：把页面之间的跳转画成连线，一眼看出交互是否接对；
- 跨页跳转、页内弹层、SPA 路由视图会被识别并标注。

### 视口与裁剪

默认开启**自动识别**：按页面的 `<meta name="viewport">` 与媒体查询断点判断端型，自动给出视口与画板范围。

| 端型 | 视口 | 画板范围 |
| --- | --- | --- |
| 手机 | 412 × 915 | 一屏 |
| 平板 | 834 × 1194 | 一屏 |
| 桌面 | 1440 × 900 | 贴合内容 |

也可以从**经典设备预设**里选：安卓（Pixel 7/8、Galaxy S、通用、大屏）、iOS 参考、网页（笔记本 / 桌面 / MacBook / 全高清）、平板。手动改动任一视口字段即关闭自动识别。

### 还原模式

- **仅样式** —— 只要视觉还原，不读交互、不建连线，也不为弹层与视图额外出稿，跑得更快；
- **样式 + 交互**（默认）—— 视觉还原之外，读页面代码得出跨页跳转、弹层与路由视图。

## 精度

在真实浏览器里排版测量，不猜 CSS：读 `getBoundingClientRect()` 与 `getComputedStyle()`，
文本用 `Range.getClientRects()` 拿到每一个视觉行的精确盒子。

本地对示例页做过**像素级对比**（真实页面 vs 复刻渲染，MAE / 255）：

| 页面 | MAE | 结构性差异 |
| --- | --- | --- |
| MD3 字体与形状 | 0.28 | 0.20% |
| 覆盖层 | 0.50 | 0.68% |
| 概览 | 1.18 | 0.82% |
| 表单 | 1.28 | 1.00% |
| 组件总览 | 1.51 | 1.19% |

剩余差异集中在**边框与圆角的抗锯齿边缘**，没有错位或缺失。

## 目录结构

```
web/               index.html（界面）· app.js（流程）
core/              内核，与插件版同一套
  engine.js        在真实浏览器里排版测量 → 快照
  session.js       流程编排、选项、自动识别、还原模式
  vfs.js           整包解析与资源内联（含本地 JS、字体）
  interactions.js  交互提取
  code-interactions.js  从页面 JS 源码读出「控件 → 目标」
  route-probe.js   运行时路由探测（兜底）
  hover-states.js / overlay-states.js / view-states.js   状态稿
  viewport.js      端型识别与设备预设
  svg.js           快照 → SVG（网页版的出口）
  lowfi.js / backdrop.js / flow.js
serve.js           静态服务器
```

## 开发

改 `core/` 之后直接刷新页面即可（`serve.js` 不做缓存）。

内核是**网页版与插件版共用的**：改 `core/` 时记得同步到插件版仓库，两个入口的行为才会一致。

## 已知限制

- 不支持 `conic-gradient`、`clip-path`、`mask`、跨域图片像素、`filter` 链；
- `<iframe>`、跨域 `<canvas>` / `<video>` 取不到像素，会留占位；
- 整包解析要求同一静态服务器下访问（不要用 `file://`）。
